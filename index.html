1. Live points leaderboard

Overall ranking: highest net points wins. FINISH and DNF net points cannot fall below the minimum Gate-1 score (round(DNF base / total gates)). DNF net = max(Gate-1 minimum, round(DNF base x gates cleared / total gates) minus point penalties). DNS = 0. If stage points tie, FINISH ranks above DNF. Overall tie-break: more FINISH results, higher SS4 net points, lower total raw time across FINISH stages, then lower race number. DNF base is frozen at the first official result; later entries do not change it. Gate totals lock after the first saved result in that SS.
2. Penalty Setup
Same rules for every SS

Configure each penalty type and its point deduction before racing. Final preset: Touch 15 points, Special Gate 5 points, Outrack 10 points and Roll Over 5 points; a Jump Gate violation is recorded as DNF using the DNF control. Roll Over applies only when the crawler comes to a complete stop with all four tyres lifted off the ground (all four tyres are in the air); a brief bounce or momentary lift while the crawler is still moving does not count. Each tap deducts points from that stage score; it does not add time or change raw-time finishing order. Values are frozen when a tap is recorded, so existing tap values remain unchanged when the preset is applied. Existing Event IDs keep their saved rules until the organiser applies the updated preset below.
