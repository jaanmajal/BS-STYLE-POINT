Overall ranking: highest net points wins. FINISH points cannot fall below the DNF score for clearing Gate 1 (round(dynamic DNF base ÷ total gates)). 4. Penalty Setup
Same rules for every SS

Configure each penalty type and its point deduction before racing. These shared rules apply to every SS. This setup is locked by the admin PIN. Each tap deducts the configured number of points from that stage score; it does not add time or change the raw-time finishing order. Values are frozen when a tap is recorded, so editing a rule affects future taps only. Removing a rule does not erase penalties already recorded.
