Overall ranking: highest total points wins. Each SS awards position points using the S1 Borneo Safari-style scale. DNF points adjust automatically to the current registered driver count: max(20, points for the last registered position minus 20); DNS = 0. Stage position is based on adjusted time (raw time plus or minus assigned penalties). Ties are resolved by points in the final SS, then number of recorded stages, then lower total adjusted time.
